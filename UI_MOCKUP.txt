User Interaction Flow:

1. Click "Load PLY 1"
   └─→ File Dialog Opens
       └─→ Select sample_cube.ply
           └─→ Cube appears in view

2. Click "Load PLY 2"  
   └─→ File Dialog Opens
       └─→ Select sample_pyramid.ply
           └─→ Both models appear side-by-side

3. Mouse Interactions:
   ├─→ Left Click + Drag
   │   └─→ Models rotate in 3D space
   ├─→ Mouse Wheel Up
   │   └─→ Zoom in (closer view)
   └─→ Mouse Wheel Down
       └─→ Zoom out (farther view)

4. Projection Toggle:
   ├─→ Click "Perspective"
   │   └─→ Natural 3D view with depth
   └─→ Click "Orthographic"
       └─→ Technical drawing view (no perspective)
